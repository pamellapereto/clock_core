Conceito técnico

O que é uma thread?

Uma thread é uma linha de execução dentro de um programa. Ela representa uma sequência de instruções que o processador pode executar. Um programa pode ter uma única thread ou várias threads trabalhando em paralelo ou alternadamente.

Em termos simples: o processo é o “programa em execução”; a thread é o “caminho de trabalho” dentro desse programa. Um editor de vídeo, por exemplo, pode usar uma thread para a interface, outra para exportação, outra para áudio e outra para efeitos.

Por que threads existem?

Threads tornam o sistema mais responsivo

Responsividade

Uma thread pode cuidar da interface enquanto outra executa uma tarefa pesada.

Paralelismo

Em CPUs com vários cores, diferentes threads podem executar ao mesmo tempo.

Aproveitamento

Quando uma thread espera dados, outra pode ocupar a CPU e reduzir tempo ocioso.

Escalonamento

Como a CPU alterna threads?

O sistema operacional possui um componente chamado escalonador. Ele decide qual thread receberá tempo de CPU, por quanto tempo e em qual core. Essa divisão cria a sensação de que muitas tarefas estão acontecendo ao mesmo tempo.

Quando existem mais threads do que cores disponíveis, a CPU alterna rapidamente entre elas. Essa troca é chamada de troca de contexto. Ela é útil, mas tem custo: salvar o estado de uma thread e carregar o estado de outra consome tempo.

Threads lógicas

SMT e Hyper-Threading

Core físico

É uma unidade real de processamento dentro do chip. Possui estruturas próprias para buscar, decodificar e executar instruções.

Thread lógica

É uma “pista” extra de execução oferecida pelo processador para aproveitar melhor partes do core que ficariam ociosas.

Hyper-Threading

Nome comercial usado pela Intel para uma forma de SMT, permitindo que um core físico apareça como duas threads lógicas.

Atenção importante

Duas threads lógicas não equivalem a dois cores físicos completos. Elas melhoram aproveitamento, mas ainda compartilham recursos internos do mesmo core.

Exemplo cotidiano

Threads em um navegador

Um navegador moderno pode executar várias threads: uma para renderizar a página, outra para processar JavaScript, outra para baixar arquivos, outra para áudio/vídeo e outras para segurança ou extensões.

Isso evita que a página inteira “congele” sempre que uma tarefa demora. Se uma aba está carregando vídeo, outra ainda pode aceitar clique, rolagem e digitação.
